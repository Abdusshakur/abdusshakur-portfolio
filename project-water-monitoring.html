Project motivation

Physical conditions become more actionable when measurements can be monitored digitally. This project explored how a connected embedded device could support visibility into a water-related system.

Technical approach

Built around an ESP8266, the prototype connects embedded monitoring with a dashboard interface. It illustrates the relationship between device-side acquisition, communication, and user-facing presentation.

System-level learning

Beyond individual sensor readings, the project strengthened my understanding of how embedded hardware, connectivity, data presentation, and reliability have to be designed as one system.

Next iteration

Document sensor specifications and calibration, evaluate network interruptions, define alert thresholds, and test long-term reliability before making operational performance claims.
