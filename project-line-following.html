Line-Following Mobile Robot

A compact autonomous robot that follows a marked path using two IR line sensors, an ESP8266 microcontroller, and PWM-based motor control.

The objective

Build a small mobile robot capable of detecting and following a high-contrast path while handling straight sections, curves, and turns.

Hardware integration

The prototype uses a NodeMCU ESP8266 controller, two infrared line sensors for path detection, and an L298N motor driver for motor actuation. PWM controls motor speed as steering decisions are made from the sensor readings.

Control logic

The controller reads the two sensor states and adjusts the motors to keep the marked line under the robot. This provides an accessible demonstration of the closed loop between sensing, control decisions, and physical motion.

Testing and results

The robot was tested on straight and curved paths, as well as sharper turns made using black electrical tape on a contrasting surface. It successfully followed the paths, with calibration required for sensor height and positioning, ambient-light sensitivity, and PWM motor-speed balance.

Lessons learned

Even simple robots are multidisciplinary: reliable performance depends on electrical connections, mechanical alignment, sensor calibration, control logic, and repeatable tests—not code alone.
